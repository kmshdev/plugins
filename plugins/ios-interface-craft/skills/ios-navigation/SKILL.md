# SwiftUI navigation

Preserve the app’s existing navigation ownership and supported SDK.

## Scope

This catalog describes coordinator-based navigation. Use its coordinator and route-shell rules when the project has chosen that architecture; SwiftUI navigation itself does not require a coordinator.
