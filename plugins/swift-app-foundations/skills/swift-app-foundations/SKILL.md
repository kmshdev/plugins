# Swift app foundations

Inspect the requested change and the project's existing architecture, then open only the relevant specialist.

| Need | Specialist |
|---|---|
| SwiftData models, queries, persistence, or migration | [SwiftData](../swift-data/SKILL.md) |
| Measured Swift or SwiftUI slowdown | [Swift performance](../swift-optimise/SKILL.md) |
| Refactor toward the project's modular MVVM-C structure | [Swift refactor](../swift-refactor/SKILL.md) |
| Design or review modular MVVM-C state and module boundaries | [SwiftUI architecture](../swift-ui-architect/SKILL.md) |

Do not introduce modular MVVM-C solely because the app uses SwiftUI. For UI controls, forms, charts, and effects, use the installed SwiftUI builder or Build iOS Apps skills when available.
